# Портфолио Аполлинарии Пилипюк

Статический сайт на основе композиции и оформления шаблона `ksu` с контентом из https://posmm.vercel.app/. Исходный экспорт `ksu/` сохранён для справки.

## Локальный просмотр

```sh
npm run dev
```

Откройте http://127.0.0.1:4173/.

## Сборка

```sh
npm run build
```

Для сборки нужен Node.js 20 или новее. Внешних зависимостей нет. Готовая папка для размещения — `dist/`. В ней только сайт Аполлинарии; исходные материалы и шаблон в сборку не входят. Конфигурация Vercel находится в `vercel.json`.

Сборка использует готовые HTML-страницы и проверяет ссылки на локальные файлы. Оригинальный шаблон `ksu/` и дубликаты исходных медиа `source-content/assets/` остаются локально и исключены из Git. При наличии этих локальных оригиналов команда `npm run generate` повторно создаёт страницы из данных через Python 3.

## Содержимое

- Главная: `index.html`.
- Все проекты: `work.html`.
- Семь страниц проектов: `work/`.
- Все тексты, исходные контакты и привязка медиа: `source-content/content.json`.
- Готовые 24 медиафайла: `assets/media/`; сведения об источниках: `source-content/media-manifest.json`.
- Сборка публикации: `scripts/build.mjs`; локальный генератор страниц: `scripts/build.py`.
- Адаптивные стили и меню: `assets/site.css`, `assets/site.js`.

## Анимации референса

В `assets/motion.css` и `assets/site.js` восстановлены сцена портрета между первым экраном и блоком «Обо мне», увеличение с 0,5 до 1 и переворот на 180° при прокрутке на экранах от 1280 px, проявление заголовков по словам, последовательное затемнение текста при прокрутке, раскрытие меню с задержками пунктов, перекатывание букв ссылок, смена стрелок при наведении, плавная прокрутка и перетаскивание декоративных фигур с инерцией. На узких экранах портрет переворачивается после появления, как в референсе. При системной настройке уменьшения движения эффекты отключаются, весь контент остаётся видимым.

В портфолио сохранены все семь проектов, фотографии, три примера публикаций PUMA и десять видео. При переносе исправлены повторяющийся скриншот LUKOIL вместо PUMA в мобильной версии источника и расширения семи видео, которые имели контейнер MP4, но назывались `.webm`.

Все 16 растровых изображений сайта обработаны официальным веб-компрессором Tinify (TinyPNG): 14 WebP сжаты повторно, две декоративные PNG конвертированы в WebP. Общий вес уменьшен с 2 368 220 до 2 009 004 байт (15,17%). Размеры изображений и прозрачность сохранены. Результаты, размеры и контрольные суммы — в `source-content/image-optimization.json`. Локальный генератор сохраняет оптимизированные файлы, не заменяя их исходными версиями. Ссылки на изображения содержат версию из контрольной суммы, чтобы браузеры и Cloudflare не использовали старые копии после публикации.

Блок услуг, демонстрационные статьи, отзывы, чужие контакты и неработающая форма шаблона не используются. Связь — через WhatsApp и Telegram из исходного портфолио.
